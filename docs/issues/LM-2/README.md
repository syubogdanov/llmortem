# LM-2: Локальные LLM для IT-контекста (Ollama)

## 1. Цель анализа

В рамках данного этапа проводится анализ локальных больших языковых моделей (LLM), пригодных для использования в IT-контексте и разворачиваемых с помощью Ollama.  
Цель анализа — выделить набор моделей, которые могут быть использованы для обработки технического текста, программного кода и связанных артефактов (логи, конфигурации, описания архитектуры), а также для формирования структурированных аналитических отчётов.

Рассматриваются исключительно англоязычные модели, поскольку они являются наиболее распространёнными и активно развиваемыми в экосистеме open-source LLM.

---

## 2. Критерии отбора моделей

При отборе моделей учитывались следующие критерии:

- ориентация на задачи программирования и анализа технического текста;
- способность работать не только с кодом, но и с алгоритмическими описаниями, разметкой и структурированными данными;
- наличие реалистичных вариантов для локального использования в условиях ограниченных вычислительных ресурсов;
- доступность модели в экосистеме Ollama.

---

## 3. Обзор выбранных моделей

### 3.1 Qwen2.5-Coder (0.5B – 32B)

Qwen2.5-Coder — семейство языковых моделей, ориентированных на задачи программирования и анализа технического текста. Модели данной линейки демонстрируют устойчивые способности к генерации и интерпретации кода, а также к работе с формализованными описаниями алгоритмов и структур данных.  
Наличие версий с различным числом параметров (от 0.5B до 32B) позволяет рассматривать Qwen2.5-Coder в качестве кандидата для локального использования. В рамках анализа модель представляет интерес как универсальное решение для работы с кодом и текстовыми артефактами пост-инцидентного анализа.

---

### 3.2 DeepSeek-Coder-V2 Lite (16B, MoE)

DeepSeek-Coder-V2 — специализированная модель, ориентированная на задачи программирования и инженерного рассуждения. Модель демонстрирует сильные стороны в анализе кода и формировании логически связных объяснений технических решений.  
Облегчённая версия DeepSeek-Coder-V2 Lite (16B, архитектура Mixture-of-Experts) делает модель потенциально применимой в локальных сценариях. В рамках анализа она рассматривается как кандидат для задач, требующих более глубокого code-reasoning.

---

### 3.3 StarCoder2 (3B, 7B, 15B)

StarCoder2 — открытая линейка моделей, ориентированных на генерацию и анализ программного кода. Модели данной серии хорошо подходят для работы с различными языками программирования и техническими текстами.  
Наличие версий размером 3B, 7B и 15B позволяет рассматривать StarCoder2 как практичный вариант для локального использования. В рамках анализа модель выступает как устойчивый baseline для сравнения с более новыми специализированными моделями.

---

### 3.4 Granite Code (3B, 8B, 20B, 34B)

Granite Code — семейство моделей, ориентированных на задачи генерации и анализа программного кода. Отличительной особенностью линейки является наличие версий с увеличенным контекстным окном.  
Модели размером от 3B до 34B позволяют рассматривать Granite Code как потенциально полезное решение для работы с длинными логами, конфигурациями и временными линиями событий в рамках пост-инцидентного анализа.

---

### 3.5 Code Llama (7B, 13B, 34B)

Code Llama — широко распространённая модель для задач программирования и анализа кода. Она поддерживает основные сценарии генерации, объяснения и модификации программного кода.  
В рамках анализа рассматриваются версии 7B и 13B как более реалистичные для локального использования, тогда как версия 34B может выступать в качестве ориентирующего baseline при сравнении возможностей моделей.

---

### 3.6 Phi-3 / Phi-3.5 (3.8B, 7B)

Phi-3 и Phi-3.5 — компактные языковые модели, ориентированные на задачи рассуждения и работы с техническим текстом. Размеры моделей (3.8B и 7B) позволяют использовать их в условиях ограниченных вычислительных ресурсов.  
В рамках анализа Phi-3 рассматривается как вспомогательное решение для задач документирования и обобщения результатов пост-инцидентного анализа.

---

### 3.7 Stable Code 3B (3B)

Stable Code 3B — компактная модель, ориентированная на базовые задачи генерации и анализа программного кода. Основным преимуществом модели является низкий порог требований к вычислительным ресурсам.  
В рамках анализа Stable Code 3B рассматривается как экономичный вариант для простых инженерных задач и предварительной обработки технического текста.

---

## 4. Сравнительный анализ

Рассмотренные модели различаются по степени специализации и потенциальным сценариям применения:

- модели Qwen2.5-Coder, DeepSeek-Coder-V2 и StarCoder2 ориентированы преимущественно на задачи программирования и code-reasoning;
- Granite Code выделяется возможностью работы с расширенным контекстом;
- Phi-3 ориентирована на задачи структурирования и аналитического изложения;
- Code Llama и Stable Code 3B могут использоваться в качестве базовых или вспомогательных решений.

---

## 5. Выводы

Проведённый анализ показывает, что экосистема локальных LLM предоставляет достаточный выбор моделей для работы с IT-контекстом.  
Для дальнейших этапов проекта целесообразно рассматривать использование одной или нескольких моделей, сочетающих способности к анализу программного кода и формированию структурированных текстовых отчётов, с учётом ограничений локальной среды выполнения.
