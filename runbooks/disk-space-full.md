# Disk Space Full

## Симптомы
- На сервере или контейнере заканчивается место
- Ошибки записи в файлы или базу
- Сервис не может создать временные файлы
- Docker / system logs сообщают о нехватке места

## Возможные причины
- Логи заняли слишком много места
- Временные файлы не очищаются
- Большие дампы, бэкапы или артефакты
- Переполнен диск с данными приложения
- Контейнеры / образы заняли весь объём

## Что проверить
1. Какие директории занимают больше всего места
2. Есть ли резкий рост логов
3. Не копятся ли временные файлы
4. Не закончился ли volume Docker
5. Не появлялись ли большие артефакты после релиза

## Быстрые действия
- Очистить временные файлы и старые логи
- Удалить ненужные Docker images / containers
- Перенести или удалить старые дампы
- Увеличить размер диска, если это возможно

## Эскалация
- Платформа / DevOps
- Команда сервиса, если источник роста — приложение
