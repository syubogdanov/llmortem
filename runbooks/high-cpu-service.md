# High CPU on Service

## Симптомы
- У сервиса высокий CPU usage
- Выросла latency
- Под начал throttling или рестарты
- Утилизация CPU держится на высоком уровне длительное время

## Возможные причины
- Бесконечный цикл или неэффективный код
- Резкий рост трафика
- Нагрузка после нового релиза
- Тяжёлые SQL-запросы
- Перегрузка очереди задач

## Что проверить
1. Когда начался рост CPU
2. Был ли релиз перед ростом
3. Какие endpoints или задачи стали самыми дорогими
4. Есть ли рост входящего трафика
5. Есть ли аномалии в логах и профайлинге

## Быстрые действия
- Увеличить количество реплик
- Ограничить тяжёлый функционал
- Откатить релиз
- Временно снизить нагрузку через rate limit

## Эскалация
- Команда сервиса
- Платформа / SRE при проблемах масштабирования
