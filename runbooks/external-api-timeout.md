# External API Timeout

## Симптомы
- Ошибки timeout при вызове внешнего API
- Медленные ответы на зависимых endpoints
- Retry-логика приводит к росту нагрузки

## Возможные причины
- Внешний провайдер деградировал
- Проблема в сети
- Слишком маленький timeout
- Слишком агрессивные retry
- Рост нагрузки на внешнюю интеграцию

## Что проверить
1. Проверить доступность внешнего API
2. Проверить latency и error rate интеграции
3. Проверить настройки timeout / retry
4. Проверить, все ли методы затронуты
5. Проверить статус-страницу внешнего провайдера

## Быстрые действия
- Временно увеличить timeout
- Уменьшить retry rate
- Включить fallback, если он есть
- Отключить неcritical интеграцию

## Эскалация
- Команда интеграций
- Backend on-call
- Внешний провайдер, если инцидент на их стороне
