# LM-2: Локальные LLM для IT-контекста (Ollama)

## 1. Цель анализа

В рамках данного этапа проводится анализ локальных больших языковых моделей (LLM), пригодных для использования в IT-контексте и разворачиваемых с помощью Ollama.
Цель анализа — выделить набор моделей, которые могут быть использованы для обработки технического текста, программного кода и связанных артефактов (логи, конфигурации, описания архитектуры), а также для формирования структурированных аналитических отчётов.

Рассматриваются исключительно англоязычные модели, поскольку они являются наиболее распространёнными и активно развиваемыми в экосистеме open-source LLM.


## 2. Критерии отбора моделей

При отборе моделей учитывались следующие критерии:

- размер модели(сколько гб весит);

- можно ли без опасения ставить на 16 RAM;

- ориентация на задачи программирования и анализа технического текста;

- способность работать не только с кодом, но и с алгоритмическими описаниями, разметкой и структурированными данными;

- доступность модели в экосистеме Ollama;

- размер запоминаемого контекста;

- средняя оценка пользователей;

## 3. Обзор выбранных моделей

Сразу нужно уточнить, что всвязи с текущими техническими ограничениями на данном этапе не планируется использование моделей, размером больше 8гб.

### 3.1 Qwen2.5-Coder (7B)

Ссылка: [тык](https://www.ai-stat.ru/model/qwen-2.5-coder-7b-instruct)

Qwen2.5-Coder — языковая моделей, ориентированных на задачи кодинга и анализа технического текста. 7 миллиардов параметоров. Обучена на 5,5 трлн токенов кода и текста. Поддерживает 92 языка программирования.
Позже рассмотрим в таблице сравнения.

Запуск: *ollama run qwen2.5-coder:7b*

### 3.2 DeepSeek-Coder-V2 Lite (16B, MoE)

Ссылка: [тык](https://github.com/deepseek-ai/DeepSeek-Coder-V2)

DeepSeek-Coder-V2 — это компактная версия мощной кодовой модели от DeepSeek. Она построенна на архитектуре Mixture-of-Experts (MoE). 16 миллиардов общих параметров, но активно использует лишь 2.4млрд.
Позже рассмотрим в таблице сравнения.

Запуск: *ollama run deepseek-coder-v2-lite:16b-q4*


### 3.3 StarCoder2 (7B)

Ссылка: [тык](https://apptractor.ru/develop/coding/starcoder-2.html)

StarCoder2 — открытая линейка моделей, ориентированных на генерацию и анализ программного кода от BigCode. Обучена на 4+ млрд токенах и более 600 я.п.
Позже рассмотрим в таблице.

Запуск: *ollama run starcoder2:7b*


### 3.4 Code Llama (7B)

Ссылка: [тык](https://ollama.com/library/codellama:7b)

Code Llama — языковая модель от Meta, ориентированная на задачи программирования и анализа кода. Поддерживает генерацию, объяснение и модификацию программного кода. Поддержка 20+ я.п.
Позже рассмотрим в таблице сравнения.

Запуск: *ollama run codellama:7b*

### 3.5 Phi-3.5 (3.8B)

Ссылка: [тык](https://systems-analysis.ru/wiki/Phi)

Phi-3.5 — компактная языковая модель от Microsoft, ориентированная на задачи рассуждения и работы с техническим текстом. Размер модели позволяет использовать ее в условиях ограниченных вычислительных ресурсов.

Запуск: *ollama run phi3.5:mini-instruct*

## 4. Сравнительный анализ

| Code Llama (7B)            | ~7–8 GB       | Да                      | 16K      | Да                |
| Phi-3.5 (3.8B)             | ~2–3 GB       | Да                      | 8K       | Да                |


| Модель                 | Ориентация на код | Работа с тех. текстом | Популярность,частота использования |
|------------------------|-------------------|-----------------------|------------------------------------|
| Qwen2.5-Coder (7B)     | Высокая           | Высокая               | ~10,7m скачиваний / 199 упоминаний |

## 5. Выводы

Проведённый анализ показывает, что лучший анализ кода из приведенных моделей у DeepSeek-Coder-V2 Lite, что неудивительно, так как среди рассмотренных это самая тяжелая модель, ну а для написания постмортемов лучше всего подойдет модель Qwen2.5-Coder (7B), которая является самой популярной среди всех рассмотренных локальных моделей.
