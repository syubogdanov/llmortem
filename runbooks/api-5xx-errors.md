# API 5xx Errors

## Симптомы
- Пользователи получают HTTP 500, 502, 503 или 504
- Резко выросло количество ошибок в API
- Алерты по availability или error rate

## Возможные причины
- Упал backend-сервис
- Сломалась связь между gateway и upstream
- Проблемы с базой данных
- Таймауты внешних зависимостей
- Ошибка после недавнего релиза

## Что проверить
1. Посмотреть, какие именно коды ошибок преобладают
2. Проверить статус backend-сервиса
3. Проверить недавние релизы
4. Проверить логи gateway и upstream-сервисов
5. Проверить доступность базы данных и внешних API

## Быстрые действия
- Перезапустить проблемный сервис, если это безопасно
- Откатить последний релиз при явной связи с выкладкой
- Временно отключить проблемную функциональность через feature flag

## Эскалация
- Дежурный backend-инженер
- Команда платформы, если проблема в инфраструктуре
