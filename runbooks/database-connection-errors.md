# Database Connection Errors

## Симптомы
- Ошибки вида "connection refused", "too many connections", "timeout"
- API отвечает медленно или падает
- Логи содержат database connection error

## Возможные причины
- База недоступна
- Закончился пул соединений
- Неверные credentials
- Проблемы с сетью между сервисом и базой
- Перегрузка базы

## Что проверить
1. Проверить доступность базы данных
2. Проверить количество активных соединений
3. Проверить настройки connection pool
4. Проверить секреты и env-переменные
5. Проверить логи приложения и метрики базы

## Быстрые действия
- Перезапустить приложение, если пул завис
- Увеличить лимит соединений, если это допустимо
- Уменьшить нагрузку на проблемный сервис
- Откатить недавний релиз, если после него начались ошибки

## Эскалация
- DBA / команда данных
- Backend on-call
